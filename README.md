# Felix Algorithm — Editorial Portfolio

Monochrome editorial portfolio for Kemono fursuiter and developer **Felix Algorithm** (`フェリックス`) from Hanoi.

## ✨ Highlights
- **Editorial Aesthetic**: Warm paper `#EFEEEB`, dark ink `#141414`, Bodoni Moda, Cormorant Garamond, and Pinyon Script typography.
- **Kinetic Motion**: GSAP 3 + ScrollTrigger for scroll-driven animations, word-by-word quote reveal, and smooth signature wipe.
- **Inertia Scrolling**: Powered by Lenis.
- **Custom Interactive Elements**: Minimal circular blend-difference cursor, floating hover previews, horizontal gallery scroll.

## 🛠 Tech Stack
- **Bundler**: Vite 8
- **Core**: Vanilla HTML5, CSS3, ES Modules
- **Animation**: GSAP 3 (ScrollTrigger)
- **Scroll Engine**: Lenis

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
